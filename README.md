# Sport Town — концепция нового сайта

Адаптивный сайт клуба на Спортивной, 18в в Тольятти. Сделан для показа клиенту по аналогии с проектом «Порядок». Все файлы для публикации находятся в `dist/`, сборка не нужна.

## Просмотр

`python -m http.server 8768 --bind 127.0.0.1 --directory dist`

Локально: http://127.0.0.1:8768/ . GitHub Pages публикует `dist/` через workflow.

## Функциональность

Адаптация для телефона, мобильное меню, просмотр трёх зон с клавиатурной навигацией, фотогалерея, направления тренировок, выбор карты и расчёт эквивалента стоимости месяца, FAQ, звонки в клуб, ссылка на действующее расписание, маршрут в Яндекс Картах. Учитываются системные настройки уменьшения движения. Фото и шрифты хранятся локально, внешние скрипты и аналитика не подключены.

## Содержание

Данные и фотографии взяты с https://sporttown.pro/new 23.11.2026; источники изображений — `sources.json`. Дизайн показывает клуб на Спортивной и не смешивает его с клубом на Громовой. Истекшая акция ко дню рождения не перенесена. Тарифы, график и коммерческие условия требуют подтверждения клубом.

Это явно обозначенная демонстрационная концепция, не официальный сайт. Формы, CRM и платежи не подключены. Кнопки записи и выбора карты звонят в настоящий клуб. Автор: Захар Лепёшкин, Persik AI.

## Проверка

`node tests/check.mjs` при работающем локальном сервере. Сценарий использует Playwright из установленного проекта «Порядок» и локальный Chromium; зависимости не нужны для сайта. Проверяет ширины 360, 390, 430, 768, 1024, 1440, 1920 px, переполнение, изображения, переключатели карт и зон, клавиатуру вкладок, галерею, мобильное меню, FAQ, ошибки JavaScript и чтение без JavaScript. Скриншоты — в игнорируемой `tmp/check/`.
